# Лендинг «Разработка сайтов на WordPress»

Статический сайт: `index.html` + папка `assets/` (картинки, иконки, стоковые фото — лицензии в `assets/img/stock/LICENSES.txt`).

- `DESIGN.md` — дизайн-система (цвета, типографика, сетка, анимации, адаптив).
- Размещение: загрузить `index.html` и `assets/` в корень сайта на хостинге.

## Что доделать перед запуском
- Форма заявки пока не отправляет данные (нужен обработчик: PHP-скрипт, Telegram-бот или квиз).
- Заменить заглушки: телефон, почта, ссылки на платформы, политика конфиденциальности.
- Заменить демонстрационные цифры (кейсы, воронка, «+38% заявок») на реальные.
