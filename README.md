# Лендинг «Разработка сайтов на WordPress»

Статический сайт на HTML, CSS и JavaScript, без сборки и зависимостей.

## Состав
- `index.html` — главная страница.
- `policy.html` — политика в отношении обработки персональных данных.
- `soglasie.html` — согласие на обработку персональных данных.
- `404.html` — страница «Не найдено».
- `.htaccess` — подключает `404.html` на хостинге с Apache.
- `assets/` — картинки, иконки и стоковые фото (лицензии — в `assets/img/stock/LICENSES.txt`).
- `DESIGN.md` — дизайн-система: цвета, типографика, сетка, анимации, адаптив.
- `_redirects`, `.nojekyll` — служебные файлы для Netlify и GitHub Pages.

## Размещение
Загрузить `index.html`, `policy.html`, `soglasie.html`, `404.html`, `.htaccess` и папку `assets/` в корень сайта.

Ссылки в меню и подвале ведут от корня сайта (`/policy`, `/#contact`), поэтому сайт должен открываться в корне домена или поддомена. На хостинге с nginx страница 404 подключается строкой `error_page 404 /404.html;` в конфигурации сайта.
