# Лендинг «Разработка сайтов на WordPress»

Статический сайт: `index.html`, `policy.html` (политика ПД), `soglasie.html` (согласие на обработку ПД) + папка `assets/` (картинки, иконки, стоковые фото — лицензии в `assets/img/stock/LICENSES.txt`).

- `DESIGN.md` — дизайн-система (цвета, типографика, сетка, анимации, адаптив).
- Размещение: загрузить `index.html`, `policy.html`, `soglasie.html` и `assets/` в корень сайта на хостинге.

## Что доделать перед запуском
- Форма заявки в блоке «Контакты» закомментирована (как на Tilda); если вернуть — нужен обработчик: PHP-скрипт, Telegram-бот или квиз.
- В `policy.html` и `soglasie.html` домен сайта не указан (написано «сайт, на котором размещена настоящая Политика», ссылки — относительные `/policy`). Раздел 7 политики перечисляет подключённые сервисы: Marquiz, JivoSite, Яндекс Метрика, CRM, почта — если список изменится, поправить и там.
- Заменить демонстрационные цифры (кейсы, воронка, «+38% заявок») на реальные.
